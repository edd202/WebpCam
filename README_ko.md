# webpCam 1.0 사용법

webpCam은 화면의 원하는 영역을 녹화해 움직이는 WebP 파일로 저장하는 Windows 프로그램입니다.

## 녹화 영역

창을 움직여 촬영할 위치를 정하고, 가장자리나 모서리를 드래그해 크기를 조절합니다. 투명하게 보이는 안쪽이 실제 녹화 영역이며 오른쪽 버튼과 제목 표시줄은 포함되지 않습니다. 표시된 가로·세로 숫자는 녹화 영역의 픽셀 크기입니다.

**Frame**에서 크기 조절 방식을 선택합니다.

| 모드 | 동작 |
| --- | --- |
| 자유 비율 | 가로와 세로를 독립적으로 조절 |
| 4:3 | 4:3 비율을 유지하며 조절 |
| 16:9 | 16:9 비율을 유지하며 조절 |
| 16:10 | 16:10 비율을 유지하며 조절 |

고정 비율은 정수 픽셀로 정확히 맞도록 크기를 조정합니다. 자유 비율로 전환하면 현재 크기를 유지합니다. 고정 비율에서는 최대화가 제한됩니다.

## 녹화 시작과 정지

**Rec** 또는 기본 단축키 **F5**를 누르면 선택 창이 숨겨지고 약 0.5초 뒤 녹화가 시작됩니다. 촬영 위치는 녹화 시작 시점의 영역에 고정됩니다.

오른쪽 제어창의 **Stop** 또는 녹화 단축키를 누르면 정지합니다. 제어창에 키보드 포커스가 있으면 Esc로도 정지할 수 있습니다.

**Rec 옆 ▾**에서 다음 옵션을 선택합니다.

- FPS: 5 / 10 / 15 / 20 / 30
- 출력 크기: 100% / 75% / 50%

FPS는 목표 속도이며 화면 크기와 컴퓨터 성능에 따라 실제 캡처 속도가 달라질 수 있습니다. 저장된 애니메이션에는 실제 캡처 간격을 반영합니다.

## 새 녹화

**New**는 현재 녹화를 비웁니다. 저장하지 않은 녹화가 있으면 먼저 확인하며, 선택한 화면 비율과 설정은 유지합니다.

## 미리보기

**View**를 누르면 녹화한 프레임을 재생합니다. 미리보기 창에서 재생과 일시정지를 전환할 수 있습니다. 미리보기는 압축 전 이미지입니다.

## WebP 저장

**Save 옆 ▾**에서 품질 50~100 또는 **무손실 WebP**를 선택한 뒤 **Save**를 누릅니다.

- 품질이 높을수록 일반적으로 파일 크기가 커집니다.
- 품질 100과 무손실은 다릅니다. 픽셀을 그대로 보존하려면 무손실을 선택하세요.
- 애니메이션은 무한 반복으로 저장합니다.
- 한 프레임만 있거나 모든 프레임이 같으면 정지 WebP가 될 수 있습니다.

저장이 완료되면 촬영 영역에 아래 안내를 약 1초간 표시합니다.

```text
저장이 완료되었습니다.
저장 파일의 전체 경로
```

저장 알림은 녹화 파일에 포함되지 않으며, 다시 녹화를 시작하면 먼저 지워집니다.

## 단축키 설정

**Save 아래 Key**를 누릅니다.

1. 설정창에서 현재 키를 확인합니다.
2. 원하는 키를 누르면 입력된 키가 표시됩니다.
3. **확인**을 누르면 적용하고, **취소**를 누르면 기존 키를 유지합니다.

기본값은 **F5**이며 단일 키 또는 Ctrl / Alt / Shift 조합을 지원합니다. F12 등 예약된 키나 다른 프로그램이 사용 중인 키는 등록할 수 없습니다. 키를 길게 눌러도 자동 반복으로 녹화가 전환되지 않습니다.

설정은 `%LOCALAPPDATA%/WebPCam/settings.json`에 저장해 다음 실행에도 유지합니다. 설정창, 저장 작업, 저장 위치 선택 및 미저장 확인 중에는 녹화 단축키를 처리하지 않습니다.

다른 프로그램에 포커스가 있어도 사용할 수 있는 전역 단축키입니다. 일부 게임에서 작동하지 않으면 webpCam을 관리자 권한으로 실행해 확인하세요.

## 실행과 EXE 빌드

- 소스 실행: Python 3.11 이상 64비트 및 Tcl/Tk를 설치한 뒤 `Start.bat` 실행
- 첫 실행: 필요한 Pillow 패키지를 인터넷으로 설치
- EXE 만들기: Windows에서 `Build_EXE.bat` 실행 → `dist/webpCam.exe` 생성
- EXE 실행: Python 설치 없이 실행하는 용도

## 녹화 범위

- 최대 60초 또는 프레임 메모리 약 256 MiB에 먼저 도달하면 자동 정지하며, 캡처한 내용은 저장할 수 있습니다.
- 프레임 메모리 한도는 앱 전체 메모리 한도가 아닙니다.
- 소리, 마우스 커서 합성 및 프레임 편집은 지원하지 않습니다.
- 녹화 영역 위에 다른 창이 올라오면 함께 촬영됩니다.
- 보호된 화면이나 일부 전체 화면 앱은 캡처되지 않을 수 있습니다.
- 화면과 녹화 파일을 서버로 전송하지 않습니다.
